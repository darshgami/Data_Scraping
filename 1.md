Act as a senior full-stack developer and automation expert.

Build a production-ready Chrome Extension integrated with a backend service using Playwright for advanced data extraction.

--------------------------------------------------

🧩 TECH STACK:

Frontend (Extension):
- Chrome Extension (Manifest v3)
- React.js (Popup UI)

Backend:
- Python (Django or FastAPI)
- Playwright (for browser automation and scraping)

--------------------------------------------------

🎯 CORE WORKFLOW:

1. User opens any website (directory or listing platform)
2. User manually searches for a product on that website
3. The search results are displayed on the page

4. User opens the Chrome Extension
5. Extension popup asks for:
   - City name (input field)

6. User clicks: "Extract & Download"

--------------------------------------------------

⚙️ DATA EXTRACTION LOGIC:

- Use Playwright in backend to:
  - Open the same URL
  - Wait for page to fully load
  - Extract ONLY visible listing data

- Extract ONLY:
  1. Company Name
  2. Company Address

❌ Do NOT extract:
- Search keyword
- Phone number
- Email
- Website URL
- Ads/platform info

--------------------------------------------------

🌍 CITY FILTER:

- User enters a City in extension popup
- While extracting data:
  - Match the city with address text
  - Include ONLY matching results

Example:
If City = "Rajkot"
→ Only include companies whose address contains "Rajkot"

--------------------------------------------------

🧠 DATA RULES:

- If Company Name missing → "N/A"
- If Address missing → "N/A"
- Remove duplicates
- Clean text (trim spaces, normalize format)

--------------------------------------------------

📁 OUTPUT:

- Generate CSV file automatically
- Columns:

| Company Name | Address |

- File should be downloaded directly after extraction

--------------------------------------------------

🔄 SYSTEM FLOW:

1. Extension sends current page URL + city to backend API
2. Backend uses Playwright to:
   - Open page
   - Scrape structured data
   - Filter by city
3. Backend generates CSV
4. Send file back to extension
5. Extension triggers download

--------------------------------------------------

⚙️ EXTENSION UI:

- Show current website URL
- Input field: City name
- Button: "Extract & Download"
- Loader while processing
- Success message after download

--------------------------------------------------

🧪 EDGE CASES:

- No matching city data → return empty CSV with headers
- Slow loading pages → use Playwright wait strategies
- Dynamic content → scroll and load more if needed

--------------------------------------------------

🎁 BONUS FEATURES:

- Add Pincode filter
- Multi-page scraping (pagination)
- Export to Excel (.xlsx)
- Progress bar for scraping

--------------------------------------------------

🔐 IMPORTANT:

- Only scrape publicly visible data
- Respect website policies
- Add delay between actions (avoid blocking)

--------------------------------------------------

Ensure clean, modular, scalable code suitable for real-world use.
